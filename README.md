# Abhinandh K Shaji — Cloud & DevOps Portfolio

Modern, high-performance portfolio website for **Abhinandh K Shaji**, Cloud & DevOps Engineer and MCA Graduate based in Bangalore, Karnataka.

Designed with a bold crimson & obsidian editorial poster aesthetic inspired by high-fashion tech layouts, featuring 3D typography subject layering, an interactive DevOps terminal, and a live CI/CD pipeline simulator.

---

## 🚀 Key Features

- **Editorial Crimson Poster Aesthetic**:
  - Full-width dark obsidian canvas (`#0c0c0f`) with crimson accents (`#dc2626`).
  - Typography: **Bebas Neue** (giant bold headlines & numbers), **Caveat** (handwriting script), and **Plus Jakarta Sans** (clean tracking typography).
  - Subject-Typography Depth: Isolated transparent portrait cutout blended seamlessly in front of the giant `PORTFOLIO` backdrop with ambient red rim lighting.
- **Showcase Projects**:
  - **Event Nano**: Full-Stack MERN Event Management Platform with RBAC, vendor bidding, and REST APIs.
  - **Ransomware Detection**: AI-Powered Cybersecurity Threat Classifier utilizing CNN & LSTM deep learning models.
  - **AWS Cloud & Kubernetes Pipeline**: Declarative Terraform IaC VPC infrastructure with automated zero-downtime microservices delivery.
- **Interactive DevOps Engine**:
  - **Bash Terminal Console**: Interactive CLI supporting commands (`help`, `whoami`, `skills`, `projects`, `deploy`, `aws`, `cat resume.txt`, `contact`).
  - **Live CI/CD Pipeline Simulator**: Step-by-step visual animation demonstrating Git -> Jenkins -> Docker -> Terraform -> K8s -> CloudWatch.
- **Printable Curriculum Vitae**: Built-in interactive modal with one-click print-to-PDF formatting.
- **Interactive Modals & Quick Copy**: Deep-dive architectural breakdowns for projects, contact modal, and one-click clipboard copying.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with SEO meta tags & Open Graph protocol.
- **Styles**: Vanilla CSS3 (Custom properties, CSS Grid, Flexbox, Keyframe animations).
- **Scripts**: Pure JavaScript (ES6+, zero dependencies, instant load times).
- **Icons & Fonts**: Google Fonts, Font Awesome 6, Devicon CDN.

## 💻 Local Setup

You can run the portfolio locally using any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8000` in your browser.
